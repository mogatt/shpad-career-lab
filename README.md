## 🔍 О проекте

Рынок вакансий содержит большое количество разрозненной информации: зарплатные вилки, требования к опыту, профессиональные навыки, формат занятости и региональные особенности. Цель проекта — объединить эти данные в удобном аналитическом сервисе и помочь пользователю получить общее представление о выбранном сегменте рынка труда.

Сервис решает несколько задач:

- сравнивает зарплатные ожидания пользователя с предложениями работодателей;
- показывает распределение зарплат в выбранном сегменте;
- позволяет анализировать вакансии по профессии, региону, опыту и условиям работы;
- визуализирует географическое распределение предложений;
- формирует ориентировочный прогноз зарплаты на основе выбранных параметров;
- помогает оценить влияние отдельных факторов на результат модели.

Проект охватывает полный цикл работы с данными: от очистки и исследовательского анализа до обучения модели и интеграции результатов в пользовательское приложение.

## 📊 Данные

Исходный массив содержал более **171 тысячи вакансий** с российских платформ поиска работы, включая hh.ru и SuperJob. После подготовки данных в аналитический набор вошло около **150 тысяч наблюдений** и более 30 характеристик вакансий.

Основные группы признаков:

- **зарплата:** нижняя и верхняя границы зарплатной вилки, валюта;
- **профессия:** название и профессиональная роль;
- **география:** страна, регион и федеральный округ;
- **опыт и условия работы:** требуемый опыт, график и тип занятости;
- **навыки:** общий перечень, hard skills и soft skills;
- **работодатель:** название, тип и отрасль компании;
- **дополнительная информация:** дата публикации и статус вакансии.

В ходе подготовки данных обрабатывались пропущенные значения, нестандартные категории, дублирующиеся записи и аномальные зарплатные значения. Зарплаты приводились к единому формату, а текстовые признаки подготавливались для последующего анализа и использования в модели.

Исходный датасет: [Яндекс Диск](https://disk.yandex.ru/d/-VDZONWnYa2TrA).

## ✨ Основные возможности

### Анализ зарплат

- расчёт количества вакансий для выбранного сегмента;
- медианные значения нижней и верхней границ зарплаты;
- интерактивное распределение зарплат;
- сравнение ожиданий пользователя с рыночными предложениями;
- анализ по регионам, профессиям, опыту и формату занятости.

### Анализ профессиональных навыков

- исследование наиболее востребованных компетенций;
- работа с hard skills и soft skills;
- подготовка текстовых признаков с нормализацией и лемматизацией;
- использование навыков при построении прогноза зарплаты.

### География вакансий

- интерактивная карта распределения вакансий;
- тепловая карта концентрации предложений;
- сравнение количества вакансий и уровня зарплат по регионам;
- таблица с региональными показателями.

### Прогноз зарплаты

- формирование прогноза по параметрам пользователя;
- учёт опыта, региона, профессии, графика, занятости и навыков;
- отображение ориентировочного уровня зарплаты;
- анализ влияния факторов прогноза на основе SHAP.

## ⚙️ Реализация проекта

### 1. Подготовка данных

Данные загружаются из ZIP-архива и проходят первичную проверку. На этапе предобработки выполняются заполнение пропусков, приведение категориальных значений к единому формату и фильтрация аномальных зарплат. Для анализа используются только наблюдения, удовлетворяющие выбранным пользовательским условиям.

### 2. Аналитический модуль

После применения фильтров рассчитываются ключевые показатели выбранного сегмента: количество вакансий, медианные границы зарплатной вилки и положение зарплатных ожиданий пользователя относительно рынка. Результаты представлены с помощью интерактивных графиков Plotly.

### 3. Географическая визуализация

Вакансии агрегируются по регионам. Для каждого региона рассчитываются количество предложений и средний уровень зарплаты. Координаты регионов используются для построения интерактивной карты Folium с тепловым слоем и маркерами.

### 4. Подготовка признаков для модели

Выбранные пользователем параметры объединяются в текстовое представление. Профессиональные роли и навыки нормализуются с использованием морфологического анализа, после чего преобразуются в числовые признаки методом TF-IDF.

### 5. Прогнозирование

Для ориентировочной оценки зарплаты используется модель CatBoost. Она получает подготовленные признаки и формирует прогноз для заданного сочетания опыта, региона, профессии, условий работы и навыков.

### 6. Интерпретация результата

Для анализа прогноза используются SHAP-значения. В интерфейсе отображается направление влияния основных групп факторов, что делает результат модели более понятным для пользователя.

### 7. Пользовательский интерфейс

Приложение реализовано на Streamlit и разделено на три тематические вкладки:

1. **Обзор рынка** — ключевые показатели и распределение зарплат.
2. **География вакансий** — карта и региональная статистика.
3. **Прогноз зарплаты** — оценка дохода и интерпретация результата.

Фильтры вынесены в боковую панель, поэтому пользователь может менять параметры и сразу видеть обновлённые результаты анализа.

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.10 или новее;
- pip.

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/mogatt/shpad-career-lab.git
cd shpad-career-lab

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
streamlit run app.py
```

После запуска приложение будет доступно в браузере по локальному адресу, указанному Streamlit.
